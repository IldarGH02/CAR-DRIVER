# 🚗 GoTrack — Учёт поездок и амортизации автомобиля

[![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)](https://github.com/gotrack/gotrack)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![React](https://img.shields.io/badge/React-18.2.0-61dafb.svg)](https://reactjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.0.0-3178c6.svg)](https://www.typescriptlang.org/)

**GoTrack** — современное веб-приложение для водителей и автопарков. Отслеживайте поездки, рассчитывайте расход топлива и амортизацию, формируйте отчёты в PDF и Excel.

## 📋 Функционал

### 🔐 Авторизация
- Регистрация с подтверждением email (6-значный код)
- Вход по email и паролю
- Защищённые маршруты

### 📊 Дашборд
- Общая статистика поездок
- Динамика расходов (графики)
- Список последних поездок

### 📝 Поездки
- Добавление/редактирование/удаление поездок
- Расчёт топлива по расходу и пробегу
- Расчёт амортизации (5 ₽/км)
- Строка расходов (опционально)

### 📑 Отчёты
- Фильтрация по периоду
- Экспорт в PDF с кириллицей
- Экспорт в Excel (XLS)
- Информация о составителе (ФИО, автомобиль, госномер)

### ⚙️ Настройки
- Профиль водителя (ФИО, автомобиль, госномер)
- Настройки валюты и единиц измерения
- Настройка ставки амортизации

### 🧮 Калькулятор
- Расчёт топлива по расходу и пробегу
- Расчёт амортизации
- Итоговая стоимость поездки

## 🛠 Технологии

### Frontend
- **React 18** + **TypeScript**
- **Zustand** — управление состоянием
- **React Router v6** — маршрутизация
- **Tailwind CSS** — стилизация
- **Recharts** — графики
- **React Hook Form** + **Zod** — формы и валидация
- **html2pdf.js** — генерация PDF
- **axios** — HTTP запросы

### Backend
- **Fastify** — серверный фреймворк
- **SQLite** — база данных
- **JWT** — аутентификация
- **bcryptjs** — хеширование паролей
- **nodemailer** — отправка email
- **TypeScript** — типизация

## 🚀 Установка и запуск

### Требования
- Node.js 18+
- npm или pnpm

```bash
# Клонирование репозитория
git clone https://github.com/gotrack/gotrack.git
cd gotrack

# Установка зависимостей фронтенда
cd client
npm install

# Установка зависимостей бэкенда
cd ../api
npm install
